# Ocean-AI: Near-Real-Time 3D Ocean Subsurface Reconstruction & What-If Digital Twin

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Desaishishir37/ocean-ai-digital-twin)

A modular, physics-informed AI system that reconstructs subsurface ocean thermal structures (15 depth levels, down to 1000m) in the North Indian Ocean from operational satellite surface observations, validated against in-situ Argo profiling floats with uncertainty quantification, real-time coastal disaster telemetry, and an interactive What-If scenario simulator.
